02 — Color Combinations From brand reference

Derived from the 2026 brand combinations sheet. These pairings are defined — use only these. Anything not shown here should be validated before use.

On Pure Black
All brand colors work on pure black. Full palette range available.
On Pure White
All colors on white. Light Gray as text fails — use only for borders on this surface.
On Dark Gray
Black, light grays, white, and yellow. Feature colors not validated on this bg.
On Light Gray
Black and dark gray only for text. Yellow as accent. Feature colors not validated.
On Luna Yellow
Black text only. No white, no gray, no feature colors on yellow. No exceptions.
On Blue / Magenta / Orange
White text only on all three feature colors at 400 stop. Black fails contrast on all three.

04 — Semantic State Colors Suggested

Keeping within the spirit of the palette — high chroma, fresh, non-clinical. These are independent from the feature bucket colors so states can exist on any screen regardless of feature color.

Positive / Success
#00C37A
Good scores, optimal metrics, goals reached. Neutral green — doesn't conflict with any feature bucket.
Warning / Caution
#F5F85D
Fair scores, approaching limits, moderate attention needed. Luna Yellow doubles as the warning state — natural fit.
Critical / Alert
#FF3B3B
Pay attention states, failed goals, urgent signals. Sharp red — clearly distinct from Strain Orange.
Informational
#2E64E4
Neutral data points, tips, LifeOS AI moments, non-urgent nudges. Maps to Recovery Blue — confirm once bucket assignment is locked.
Note on Warning = Yellow: This is a strong suggestion — Yellow is the brand primary and naturally reads as "pay attention" without being alarming. If Yellow is being used heavily as a UI accent (e.g. CTA buttons), we should keep it as warning-only and use a muted amber (#F0B429) for decorative yellow moments to avoid confusion.
05 — Stroke & Border Tokens Minimal, thin

All strokes are 1px. Vibe: minimal, barely-there lines that define space without adding visual weight. No 2px dividers, no heavy borders.

Border/Ghost
#F0F0F0 — 1px
Layout dividers, between-row separators. Barely perceptible.
Border/Subtle
#D9D9D9 — 1px
Card borders, input fields at rest. Standard structural border.
Border/Default
#9E9E9E — 1px
Section separators that need to read. Selected tabs, hover states.
Border/Emphasis
#000000 — 1px
Focused input, selected card, active/pressed states. Black, sharp.
Border/Brand
#F5F85D — 1px
Highlighted metric, current-day indicator, brand accent border.
Border/Critical
#FF3B3B — 1px
Error state on input fields, critical metric call-outs.
Stroke weight is always 1px. The minimal vibe comes from restraint in color, not thickness. If a border is doing structural work, use Border/Subtle. Only reach for Border/Emphasis and above for interactive feedback.
